# hello-c

A small C program that asks for the user's name and greets them. I built it to practice C and the Git/GitHub workflow (branches, commits, pull requests).

## Features
- Asks for the user's name
- Checks that a name was actually entered
- Greets the user through a separate `greet()` function

## Tech Stack
- C
- gcc / clang

## Getting Started

### Prerequisites
- A C compiler (gcc or clang)

### Build and Run
    gcc main.c -o hello.out
    ./hello.out

## Usage
    What is your name? Anna
    Hello, Anna!

## What I Learned
- Working with branches and pull requests
- Checking the return value of `scanf`
- Splitting code into functions
